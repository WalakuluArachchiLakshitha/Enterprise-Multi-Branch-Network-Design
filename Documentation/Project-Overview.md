# Project Overview

## 1. Project Title
Enterprise Multi-Branch Network Design, Implementation & Security

## 2. Purpose
The purpose of this project is to design, simulate, implement and document an enterprise network that connects a central head office and two branch offices. Cisco Packet Tracer is used as the network simulation environment.

## 3. Network Sites
- Colombo Head Office
- Kandy Branch
- Galle Branch

The current topology screenshot shows WAN connections between the three sites and separate network areas within each location.

## 4. Head Office Network Areas
The current diagram identifies several logical areas at the Colombo site:
- Department/user VLANs, including Admin, HR, Finance, IT and Engineering
- Server farm
- DMZ
- Corporate and guest wireless networks

The exact device configuration, IP addressing and service status should be confirmed from the latest Packet Tracer file and corresponding configuration evidence.

## 5. Branch Network Areas
The Kandy and Galle branch diagrams show user and wireless network segments connected through branch network devices. The current diagram includes separate user and Wi-Fi subnet labels at each branch.
