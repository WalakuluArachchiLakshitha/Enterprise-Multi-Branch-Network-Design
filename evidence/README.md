# Project Evidence

This directory contains screenshots demonstrating the implementation, configuration, and testing of the Enterprise Multi-Branch Network.

## Evidence Categories

- Network topology
- VLAN configuration
- Trunking and EtherChannel
- Rapid PVST+ and BPDU Guard
- Inter-VLAN routing and HSRP
- OSPF and WAN connectivity
- Firewall configuration
- Server connectivity and services
- End-to-end network testing

Screenshots will be organized and named systematically (E-01, E-02, E-03, etc.).
